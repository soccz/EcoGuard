# 한계와 다음 검증

## 반드시 함께 읽어야 할 경계

### 공개 코드는 재구성한 베이스라인이다

대회 당시 정적 시연 화면은 남아 있지만, OCR·Legal RAG·산림 모델의 전체 운영 코드는 보존돼 있지 않습니다. 현재 src/ecoguard는 발표의 기술 논지를 검증 가능하게 만들기 위해 새로 정리한 공개 베이스라인입니다. 이를 당시 제품 백엔드의 원본이나 복원본으로 표현하지 않습니다.

### 모든 사례 데이터는 합성이다

기업, 거래, 문서, 좌표, 배출계수와 가격은 시연용 합성 사례입니다. 실제 기업 성능, 실제 은행 연동, 실제 통관 결과를 뜻하지 않습니다. 법령 링크와 버전은 공식 EUR-Lex 통합본을 가리키지만 한국어 요약은 팀 작성 비공식 메타데이터입니다.

### OCR 모델은 포함하지 않는다

입력 JSON은 OCR·표 추출·수기 입력 어댑터가 반환했다고 가정한 레코드입니다. 저장소가 증명하는 범위는 별칭 매핑, 단위 정규화, 후보값·출처 보존, 문서 간 충돌 탐지입니다. 스캔 품질별 문자 인식률은 평가하지 않습니다.

### 법률 검색 평가는 작다

CBAM·EUDR 8개 조문 메타데이터와 5개 질문으로 구성한 최소 평가셋입니다. hit@3=100%는 이 고정된 사례에서 기대 citation을 회수했다는 뜻일 뿐, 모든 EU 규정이나 모든 표현에서 정확하다는 뜻이 아닙니다. 한국어 요약은 기술 검색용이며 공인 번역문이 아닙니다.

### CBAM 결과는 노출도 시나리오다

가격, 배출집약도, 적용계수는 합성 입력입니다. 무상할당 조정, Article 9의 실제·기본 탄소가격 변환, 분기별 인증서 가격, 품목별 세부 규칙과 면제·검증 절차를 모두 구현한 법정 계산기가 아닙니다. 특히 기본값 시나리오에서 사용하는 `origin_carbon_price` 입력은 현행 Article 9의 제3국 탄소가격·인증서 감축 의무액 계산이 아니라 단순 민감도 비교입니다. 실제 업무에서는 시점이 기록된 공식 자료와 전문가 검토가 필요합니다.

### 산림 변화는 합성 NDVI 기준선이다

6×6 red/NIR 픽셀의 임계값 기반 변화 탐지입니다. 실제 위성 보정, 구름 제거, 공간 정합, 토지피복 분류, 현장 검증, CNN/XAI, 생산지 경계 처리를 포함하지 않습니다. 대회 자료에 등장한 정확도 수치는 원 데이터와 평가 코드가 없어 공개 성과로 사용하지 않습니다.

### 인간이 최종 판단한다

PASS·REVIEW 같은 신호는 증빙을 어디부터 확인할지 돕는 큐입니다. 법적 적합성, 금융 승인·거절, 통관 가능 여부를 자동으로 확정하지 않습니다.

## 다음 단계

| 우선순위 | 다음 검증 | 완료 조건 |
|---|---|---|
| 1 | OCR 어댑터 평가 | 공개 스캔셋에서 필드별 정확도와 실패 사례 공개 |
| 2 | 스키마 확장 | 단위·언어·표 변형 fixture와 문서 우선순위 테스트 |
| 3 | Legal retrieval 확대 | 버전이 기록된 공식 코퍼스, 더 큰 질문셋, recall@k·citation 정확도 |
| 4 | CBAM 방법론 검토 | 품목·기간별 공식 규칙과 입력 출처 manifest, 전문가 검토 기록 |
| 5 | 산림 데이터 검증 | 라이선스가 명확한 공개 위성 타일, ground truth, 공간 분할 평가 |
| 6 | 운영 경계 검증 | 감사 로그, 권한, 개인정보, 모델·규정 버전 관리 |

실제 파일럿을 주장하려면 입력 데이터의 사용 권리, 익명화, 평가 설계, 실패 기준, 법무·규제 검토를 먼저 문서화해야 합니다.
